# Запуск сценариев

Каждый блок вводите из папки, где лежат `benchmark_fanet.py` и `the-one`.

Один прогон The ONE пишет оба журнала. Если сценарий уже запускался, для второго отчёта достаточно команды бенчмарка.

## LinkBudgetReport

### fanet_halve

```text
cd the-one
.\one.bat -b 1 fanet_halve.txt
cd ..
python benchmark_fanet.py the-one\reports\fanet_halve_LinkBudgetReport.txt --csv results_fanet_halve.csv
```

### fanet_rotate

```text
cd the-one
```

## LinkQualityReport

Журнал качества связи появляется в том же прогоне, что и link budget.

### fanet_halve

```text
cd the-one
.\one.bat -b 1 fanet_halve.txt
cd ..
python benchmark_fanet.py the-one\reports\fanet_halve_LinkQualityReport.txt --csv results_fanet_halve_quality.csv
```

### fanet_rotate

```text
cd the-one
.\one.bat -b 1 fanet_rotate.txt
cd ..
python benchmark_fanet.py the-one\reports\fanet_rotate_LinkQualityReport.txt --csv results_fanet_rotate_quality.csv
```

### fanet_split

```text
cd the-one
.\one.bat -b 1 fanet_split.txt
cd ..
python benchmark_fanet.py the-one\reports\fanet_split_LinkQualityReport.txt --csv results_fanet_split_quality.csv
```

### fanet

```text
cd the-one
.\one.bat -b 1 fanet.txt
cd ..
python benchmark_fanet.py the-one\reports\fanet_LinkQualityReport.txt --csv results_fanet_quality.csv
```

Чтобы считать качество связи только по мощности на приёме, в файле сценария замените `LinkQualityReport.model = reliability` на `LinkQualityReport.model = rxPower` и снова введите блок этого сценария из раздела LinkQualityReport.
