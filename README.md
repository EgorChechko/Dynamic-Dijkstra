# dynamic_graph

Алгоритм реализует операцию изменения веса ребра и пересчет кратчайших расстояний только в затронутой части графа.
Для использования нужен только файл dynamic_graph.py
## Вход

Граф задается списком ребер и списком смежности

Вершины нумеруются `1 .. N`. Индекс `0` в массивах не используется.

- Число вершин в графе
- `graph[v]` — список соседей `v`. Ребро записывается в обе стороны.
- `W[(u, v)]` и `W[(v, u)]` — один и тот же вес, число `> 0`
- Номер стартовой вершины
## Пример

Источник — вершина `1`. Один и тот же граф задан списком рёбер и списком смежности.


Предполагается что задается неориентированный граф

```python
from collections import defaultdict
from math import inf
from dynamic_graph import DynamicGraph, full_dijkstra

# список рёбер: (начало, конец, вес)
edges = [
    (1, 2, 1),
    (2, 3, 1),
    (3, 4, 1),
    (1, 3, 4),
    (2, 4, 8),
]

# список смежности: вершина -> соседи
graph = defaultdict(list)
graph[1] = [2, 3]
graph[2] = [1, 3, 4]
graph[3] = [2, 1, 4]
graph[4] = [3, 2]

W = defaultdict(lambda: inf)
for a, b, w in edges:
    W[(a, b)] = W[(b, a)] = w

g = DynamicGraph()
g.init(4, graph, W, 1) # 4 - число вершин, 1 - стартовая вершина

g.changeEdgeWeight(2, 3, 10)  # поменять вес у ребра 2-3 на 10 и пересчитать расстояния
g.changeEdgeWeight(1, 3, 2)

# g.d[1:] == [0, 1, 2, 3]
print(g.d) # вывести обновленные кратчайшия расстояние от 1 до всех вершин
```


## Поля DynamicGraph

| Поле | Смысл                                                                                                   |
|---|---------------------------------------------------------------------------------------------------------|
| `g.d[v]` | Расстояние от источника.                                                     |
| `g.P[v]` | Родитель в дереве.                                                                                      |
| `g.childrens[v]` | Список детей вершины v                                                                                  |
| `g.W` | Текущие веса в графе                                                                                    |
| `g.fallback` | Доля вершин, после которой увеличение веса считается заново Дейкстрой. По умолчанию `1` (не вызывается) |


## Операции

```python
g.changeEdgeWeight(a, b, new_w)  # уменьшение или увеличение веса
g.changeStart(4)                 # Изменить стартовую вершину. Приведёт к recompute()
g.recompute()                    # Запуск дейкстры и пересчет полей
```

После вызова этих функций обновляются поля у объекта DynamicGraph

## Описание работы методов

### `init`

Конструктор создаёт объект с незаполненными полями и значением `fallback`, равным `1`. Метод `init(N, graph, W, start)` сохраняет число вершин, список смежности, веса и источник, строит внутренний список рёбер с весами и вычисляет кратчайшие пути алгоритмом Дейкстры. По полученным родителям восстанавливается дерево: `P[v]` задаёт родителя вершины, `g.childrens[v]` — список её детей. Источник получает расстояние `0` и родителя `-1`. Недостижимая вершина сохраняет расстояние `math.inf` и родителя `-1`.

Повторный вызов `init` заново строит расстояния и дерево по переданным данным. Значение `fallback`, заданное у объекта, при этом сохраняется. Методы `changeEdgeWeight` и `changeStart` до первого вызова `init` завершаются с ошибкой `RuntimeError`.

### `changeEdgeWeight`

Метод `changeEdgeWeight(x, y, new_w)` записывает новый вес ребра в обоих направлениях и приводит в соответствие расстояния и дерево. Порядок концов ребра произволен. Текущий вес читается из `W`; отсутствующая пара вершин рассматривается как ребро веса `math.inf`. При равенстве нового и текущего веса поля не изменяются. Меньший вес обрабатывается как улучшение путей, больший — как их удлинение.

Чтобы новое ребро сохранилось при последующем полном пересчёте, обе вершины предварительно добавляются в списки смежности друг друга. После этого вызывается `changeEdgeWeight`.

**Уменьшение веса.** Концы упорядочиваются так, чтобы расстояние первого от источника не превосходило расстояние второго. Если расстояние второго конца уже не больше суммы расстояния первого конца и нового веса, ребро не улучшает ни одного пути, и метод завершается. В противном случае второй конец получает расстояние, равное этой сумме, и родителем становится первый конец. Далее улучшение распространяется по графу в порядке неубывания расстояния. Вершина меняет расстояние и родителя, когда через уже обновлённую вершину находится строго более короткий путь.

**Увеличение веса.** Расстояния и дерево изменяются, когда ребро входит в дерево кратчайших путей. В остальных случаях метод записывает новый вес и завершается. Если ребро входит в дерево, берётся тот его конец, для которого второй конец является родителем, и рассматривается поддерево путей, проходивших через это ребро. Вершины обходятся в порядке прежнего расстояния от источника. Для вершины ищется сосед, ещё не отнесённый к затронутым, через которого прежнее расстояние сохраняется. При наличии такого соседа вершина меняет только родителя, а пути её потомков остаются прежними. При отсутствии такого соседа вершина относится к затронутым, и обход продолжается по её детям.

Когда число затронутых вершин превышает `g.fallback * N`, локальный разбор прекращается и вызывается `recompute`: расстояния и дерево строятся Дейкстрой по всему графу. Иначе расстояния затронутых вершин сбрасываются, связи с прежними родителями удаляются, и внутри этой области заново строится дерево кратчайших путей. Начальные значения берутся по рёбрам, входящим в область из незатронутых вершин.

Поле `g.fallback` принадлежит данному объекту и по умолчанию равно `1`.

```python
g.fallback = 0.3
```

При значении `1` порог равен `N`. Число затронутых вершин не превосходит `N`, поэтому увеличение веса завершается локальным разбором. Такой разбор быстрее полной Дейкстры, пока затронута небольшая доля вершин. При большой доле его трудоёмкость сопоставима с одним полным пересчётом. Значение `0.3` сохраняет локальный разбор для изменений в пределах 30% вершин и переводит более крупные увеличения на `recompute`. Вызовы `changeStart` и `recompute` выполняют Дейкстру по всему графу при любом значении `fallback`.

### `changeStart`

Метод `changeStart(start)` заменяет источник и вызывает `init` с текущими числом вершин, списком смежности и весами. Расстояния и дерево строятся заново от новой стартовой вершины. Значение `fallback` сохраняется.

### `recompute`

Метод `recompute` повторно вызывает `init` с текущими числом вершин, списком смежности, весами и источником. Расстояния и дерево вычисляются Дейкстрой по всему графу. Значение `fallback` сохраняется. Внутренний список рёбер при этом строится заново из списка смежности и `W`, поэтому в списке смежности должны присутствовать все рёбра, которые требуется учесть.

### Ограничения

Алгоритм применяется к неориентированному графу с одним источником и положительными весами. При нулевом весе порядок обхода поддерева по прежнему расстоянию перестаёт соответствовать зависимостям путей. Объект не рассчитан на одновременные вызовы из нескольких потоков.
